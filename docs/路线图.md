## 下一步

1. **真机性能基线**: 浏览器端打断延迟、识别准确率、热词命中率。
2. **评测集**: 固定题库 + 人工标注评分, 监控评分一致性与模型漂移。
3. **真实人脸/活体模型**: 接入厂商 SDK, 把 `assurance` 从 development-only 提升。
4. **AI 数字人**: 形象与口型同步 (当前只有说话状态动画)。
5. **云端部署**: 上线到云服务器 + 域名 + HTTPS。
6. **移动端适配 / 小程序**。
7. **多区域与灰度**: 按租户灰度、A/B 评分策略、成本看板。

## 明确不做

- **AI 自动淘汰**: 录用决策始终由人做出并署名。
- **AI 伪装真人**: 面试开始即明确告知本轮由 AI 主持。
- **情绪识别 / 面相分析**: 缺乏可靠依据, 容易产生歧视性结论。
- **录像永久保留**: 默认 90 天, 到期清理。
